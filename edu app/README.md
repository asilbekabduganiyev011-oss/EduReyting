## 📱 Ilovani telefonga o'rnatish

### Android:
1. Chrome brauzeri orqali oching
2. Yuqoridagi 3 nuqta (⋮) menyusini bosing
3. "Bosh ekranga qo'shish" ni tanlang
4. ✅ Ilova telefonda paydo bo'ladi!

### iPhone (iOS):
1. Safari brauzeri orqali oching
2. Pastdagi ulashish (📤) tugmasini bosing
3. "Bosh ekranga qo'shish" ni tanlang
4. ✅ Ilova iPhone da paydo bo'ladi!

## 🚀 Ilovani internetga chiqarish (bepul)

### Netlify orqali (eng oson):
1. https://netlify.com ga kiring
2. Ro'yxatdan o'ting (bepul)
3. Barcha fayllarni zip qiling va sudrab tashlang
4. ✅ Sizga link beriladi — barcha O'zbekiston ishlata oladi!

### GitHub Pages orqali:
1. github.com da yangi repo yarating
2. Barcha fayllarni yuklang
3. Settings → Pages → Branch: main → Save
4. ✅ yourname.github.io/edureyting manzili paydo bo'ladi!
